# Dockrunner — Введение

Dockrunner — CI/CD сервис для тестирования и развёртки студенческих ИТ-проектов.

> Просто загрузите Dockerfile и получите рабочий контейнер с доменом и HTTPS.

## Что это?

Сервис предоставляет:

- **Сборку** из Git-репозитория или Dockerfile
- **Запуск** контейнеров на воркерах (worker-01..06)
- **Домены** и автоматический TLS через Caddy
- **Логи** и метрики в реальном времени
- **Env-конфиги** до 10 на пользователя
- **Volumes** внутри настроек контейнера

![Скриншот дашборда](../docs/screenshots/dashboard.png)

## Архитектура

```
Git repo -> Build -> Scheduler -> Worker Node -> Docker run
```

Каждый контейнер получает `hostPort` из пула 3000-3004 (лимит 5 портов на пользователя).
